Network Intrusion Detection

Machine learning · 2025

04

NetWatch

Network monitoring & threat detection · 2026
  • Java desktop app that polls live TCP connections on Windows every few seconds, runs them through a rule engine (blocklisted IPs, unexpected listening ports, repeated endpoints) and raises severity-rated alerts in a real-time dashboard.
  • Layered Swing / JDBC / MySQL design with session-based history, LAN device discovery, a multi-threaded port checker, alert triage and CSV export. It keeps monitoring even when the database is offline.
